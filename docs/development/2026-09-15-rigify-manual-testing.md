## 人工与自动验证的分界

自动启动、注册数量、RNA 属性、生成对象与文件重载检查由本轮实现验收另行记录。上述自动结果不会把 RG 状态改为“已测试”或“通过”。人工仍须观察入口是否容易找到、窗口与控件是否清楚、生成后的实际操控表现，以及原有偏好的迁移结果。

全部操作使用临时场景；旧偏好和 Feature Set 的保留验证使用副本。没有已有兼容 Feature Set 时，RG-04 保持待测并备注缺少该样本，不为完成清单下载不明扩展，不推断为通过。只要求已安装且兼容的旧状态保持；未安装推荐项和已经从磁盘删除的模块不冒充已安装记录。

Rigify 主体默认内置，不代表第三方 Feature Set 自动安装或启用。自建测试文件的生成脚本及驱动沿用 Blender 原有文件信任机制，不能为了验证而全局降低脚本安全设置。遇到原生信任提示时记录提示及选择；不把文件的信任限制误报成需要安装 Rigify。

恢复工厂设置会按 Blender 原生语义重置当前临时配置与场景，因此 RG-06 使用独立副本，不用这一重置步骤判断 RG-04 的普通启动偏好保留。反馈至少记录 RG 编号、构建标签、启动方式、通过或失败、实际现象；只在 GitHub 确认提交后才算公开反馈。
