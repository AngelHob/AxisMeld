# 中英文界面与按钮翻译

日期：2026-10-12。用户要求为所有按钮增加中文翻译，并将语言缩减为中文、英文两个版本。

## 交付范围

中文采用简体中文（zh_HANS），英文采用en_US。沿用Blender原生语言切换和中文词库，补齐AxisMeld全部固定热盒、伴随列表、菜单、灰占位、Options、偏好及内置Rigify按钮文案。显示当前选择的语言，中文与英文不并排挤占按钮空间；默认英文保持，选择简体中文后内置界面显示中文。用户对象/骨骼/材质/工作区等数据名称、路径、命令ID、快捷键符号与标准格式名称保持其实际内容。

本批新增专属补充词库及覆盖验证，不改建模算法、命令绑定、菜单层级、灰项能力、Options正文隔离或既有18px列表行高。方向按钮仍以Views布局和实际命中几何为标杆；字体测量、绘制及说明排版使用同一实际译文，中文较长时允许原有布局规则加宽及底部/侧边避让。

## 实现

1. 原生39,914条有效简中PO译文继续复用，AxisMeld词典补齐固定目录及内置UI文案，通过bpy.app.translations注册并随内置模块生命周期注销。英文源目录与稳定ID保持，翻译只发生在显示边界。
2. 热盒C++测宽、绘制、Views紧凑标签和说明统一调用翻译；动态对象名不参与翻译。Python原生菜单的译文测宽与真实按钮显示一致；拼接说明先译模板再填数据。
3. 安装AxisMeld两语言清单（保留英文ID1、简中ID13），只编译/安装zh_HANS MO。旧Automatic或其他语言偏好在原生加载时规范化到英文，避免稀疏locale空指针；显式locale同样约束。保留字体栈和中文字体，以显示任意用户数据中的字符。
   内置工作区标签在显示及测宽时翻译，工厂启动保留其真实名称，避免语言切换破坏Modeling工作区识别；旧文件中已经保存的“建模”名称继续兼容。用户自定义的工作区名称不改写。
4. 全量固定目录、Recent命令、公开属性和内置Rigify文案核对中文覆盖；专有名词、数字、坐标轴、文件格式等保持项显式登记，不能将原文回退误记为完成翻译。
   原生新功能的固定标签通过真实RNA与Menu/Panel检查补词；必要上下文分别注册。Cavity原生PO将英文自留词有限修订为“腔体”，与现有“腔体曲线/腔体遮罩”术语一致，不改变通用翻译引擎或用户数据。

## 验证与发布

先记录未译基线，再验证词库完整性、两个语言枚举、旧偏好迁移、动态数据名保护与注册重载。新原生构建测试简中/英文切换，热盒和各菜单文字/宽度、Options齐右、18px列表、低窗口说明及100%/150%缩放；保存语言后重启验证。完整包使用干净候选安装，核对唯一zh_HANS资源与两项语言清单，独立解压/工厂启动及公开下载校验。

完成后更新修改日志、现有按入口测试清单和公开测试页，保留全部旧编号及人工结果，提交推送GitHub并发布对应预览包。自动覆盖与GUI检查不代替术语自然程度、鼠标手感和全部原生界面的人工验收。
