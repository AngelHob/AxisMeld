# 完整原生预览包静态审计边界

本工具只读取安装目录、源码和 ZIP；只向调用方指定的安装目录外 report 写入结果。静态 PASS 不证明原生二进制由指定源码编译，不替代实际启动、GUI、portable 和另一台机器验证。

独立审阅用隔离的最小 Git/install/ZIP 样本复现三个发布门禁遗漏，修订限于以下契约：

1. `scripts/modules/axismeld` 与 `scripts/modules/rigify` 是完整受管目录。正式 staging/extract 的实际文件集合必须等于指定提交的集合；不能仅凭自生成的 `files` 清单接受源码外残留脚本。candidate 使用当前源码集合，并仍允许列入清理待办的缓存文件。受管目录里的非 Python 资源也按来源逐字节核对。
2. 隐私检查的文本范围保持原有后缀集合；先识别 UTF-32/UTF-16 BOM，再处理 UTF-8。不能静默跳过无法解码的已选文本，错误只报告相对文件名。它是个人目录/私人站点模式检查，不是任意密钥或二进制隐私内容的通用扫描器。
3. ZIP 条目先去除目录的单个末尾 `/` 并规范化身份；文件/目录同名、大小写冲突、作为其他条目祖先的文件均拒绝。所有文件仍必须与解压安装清单逐字节一致；正常空目录可以保留。

回归使用临时最小 Git 仓库、安装目录和 ZIP，不运行 Blender，不改真实候选包。覆盖正常正式清单/ZIP、残留受管脚本与数据、UTF-8/16/32 私人文本、无法解码文本、ZIP 文件/目录及祖先冲突，并复查只读行为。真实 candidate 另跑以确认没有误拒绝正常安装。
