# GUI 输入与不可用提示修整

日期：2026-10-11。基线：`098ae882c39d209e29c34fc9a0a98dad8ff45839`。

本轮延续用户已授权的 GUI / 交互优先范围，不增加建模或蒙皮算法。

## 本轮范围

1. 修复工具热盒使用带修饰键的自定义快捷键时提前取消的问题。会话保存实际唤出事件的修饰键，保持默认 QWER、持键反复 LMB 唤出、松键及失焦取消语义。
2. 快捷键首选项中，AxisMeld 语义命令显示实际功能名称，并可按该名称搜索。保留原生及未知命令的名称回退、operator 标识符搜索和按键搜索。
3. Rigging 不可用的原生入口显示能说明恢复条件的悬停提示。使用不可执行的按钮，继续禁止错误上下文下展开原生子菜单，不改变模式或选区。

## 实现与验证

- 输入：`view3d_axismeld_hotbox.cc` 与针对性事件回归；验证 Ctrl 自定义键、重复 LMB、修饰键释放和默认工具会话。
- 快捷键：`rna_keymap_ui.py` 与集中命令标签；验证真实 RNA 条目、功能名称搜索、原生/未知命令回退。
- 灰项：`space_axismeld_native_rigging.py` 与上下文绘制测试；验证恢复条件、不可执行、无错误菜单展开和已可用入口不受影响。
- 根控独占 GUI，使用独立候选目录；自动化结果不写入人工测试状态。完成后追加稳定人工编号、修改日志及公开页面，并提交推送。运行时代码改变则发布对应源码的独立预览包，不覆盖旧版。
