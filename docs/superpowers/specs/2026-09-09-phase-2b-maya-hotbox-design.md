# Phase 2B：Maya 主热盒与中央视图菜单

日期：2026-09-09。类型：现有热盒子系统的交互架构调整。
状态：用户已确认聊天方案并于 2026-09-09 确认本书面规格；Phase 2B 正在实施，尚未整体交付或人工验收。
源码检查基线：`47c832380de`，工作树 `axismeld/phase-2a`。本文件不表示该基线已实现新设计。

## 1. 用户反馈与修正目标

用户手测认为旧版热盒体验明显不同：Maya 按住空格先出现菜单目录，在中央 Maya 区域
按住右键才出现视图 marking menu。要求对齐该操作链，并提前规划主菜单目录，尽量接近 Maya。

当前 `view3d_axismeld_hotbox.cc` 直接绘制四向视图，且只在中心 LEFTMOUSE 按下时开始划选。
这是 Phase 2A 规格本身的简化，不是已证明正确的 Maya 交互。旧测试成功只能证明旧契约。

本规格替代 Phase 2A 的“空格直接显示四向视图、中心仅左键、精确对角无命令”契约。
保留其单/四视图数值缓存、上下文隔离、裁剪安全、取消清理及独立构建验证要求。
Global 对象缩放保持 Blender 原生行为，无开发计划；Phase 1.1 的审核状态不因本规格改变。

- 本机 Maya 2026 `scripts/startup/HotboxCenterMenu.mel`：七个视图方向及 Hotbox Style 列表入口。

## 3. 方案及本轮范围

选择“原生输入/绘制 + 声明式菜单目录 + 语义命令适配层”。只修改鼠标键不能补齐层级；
一次实现 Maya 全部菜单会扩大到绑定、动画、渲染及 UV 算法，超出当前建模重点。

### 3.1 Phase 2B 必须交付

1. Space 主热盒的公共、当前视窗、中央功能、Modeling 目录行；目录顺序固定。
2. 中央右键七视图菜单，左右中键的默认行为与独立用户覆盖机制。
3. 主菜单按下、拖选、子菜单、松开提交，及完整的 Space 生命周期。
4. 已有语义命令的实际入口：聚焦、显示模式、选择模式、W/E/R、单/四视图和七视图。
5. Hotbox Controls 的菜单行显隐、三种显示样式、透明度；与个人配置分层。
6. Recent Commands 的有界、可安全重放记录。
7. 建模与 UV 目录和语义接口规划清单，明确可用、适配、未接入，不以空壳冒充功能。

完整建模命令填充、周边四区全部功能、UV 工作区和算法、动画/绑定/FX/渲染模块是后续独立批次。
本轮不扩大 Space 的生效范围：仍仅本预设的 3D WINDOW，Object 或 mesh Edit Mode。
UV 编辑器中 Space 的上下文交互另立规格；本轮只准备从 3D 热盒调用 UV 模块的接口。

## 4. 菜单结构与显示

详细目录见 [Maya 热盒菜单对照清单](../../maya-mapping/hotbox-maya2026.md)。该表的阶段不是完成状态。

默认采用完整样式；自上而下：公共菜单行、当前视窗菜单行、中央功能行、Modeling 菜单行。
中央功能行包含 Recent Commands、AxisMeld 中央区域、Hotbox Controls；中央区域在原始按键指针处。
各行围绕中央区域排布，保持 Maya 的分组与常用英文名称，不复制全应用窗口布局。
默认不展示没有已接入功能的其他功能组；目录不随对象/组件模式重排，仅改变项目可用状态。

- 中央标识为 AxisMeld，对应 Maya 的 Maya 区域；不使用 Autodesk 标志。
- 顶级未接入目录可见但禁用，提示“未接入”；不弹出写着已完成的空菜单。
- 已有目录内，已规划未接入项目禁用；适配项目给出具体差异说明；无选择等临时条件也说明原因。
- 英文原名作为稳定识别，翻译走 Blender 本地化；菜单身份不使用可变显示文字。
- 每个下拉菜单保留分组、分隔符、层级；有真实参数入口时才显示 option box，不能用装饰方块代替功能。
- 允许主菜单点击后再移入子菜单，也支持从按下直接拖选；同一次手势只提交一个叶命令。

### 边缘与小视口

划选原点不得自动移位或吸附鼠标。内区中央按钮以原始指针居中；真实边角处允许中央按钮
向视口内扩展以完整容纳文字，必须包含原始指针及原有可见命中部分，并使用同一矩形绘制/命中。
Space 捕获位置与随后鼠标按下的划选原点各自保持实际值，不得从调整后的按钮中心反推。
12 像素为划选死区，不另用它定义中央按钮点击范围。此边缘适配修正原先“命中区完全不变”
与“文字不裁切”在真实角点的冲突；不改变七向扇区和手势方向。
空间足够时严格保持公共、当前视窗、中央三入口、Modeling 的行排列。真实边角若该排列与
固定中央按钮冲突，只允许中央 AxisMeld 按钮留在原点附近，其他行作为连续有序组向内避让：
公共、当前视窗、Recent/Controls、Modeling；不重复中央按钮，不改变目录树或同组项目顺序。
这是边缘排布特例，不允许随对象模式重排菜单。主菜单过长时采用保持顺序的滚动/溢出列表，
下拉菜单按可用空间向内翻转，视觉位置和命中区域一致。主菜单标题与可点击叶项不得沿用
Phase 2A“裁掉也可交付”的策略。七向菜单在空间不足时可压缩文字绘制间距，但方向扇区和
真实手势原点不变。本轮受支持视口下限为 480×320 逻辑像素，测试 UI 缩放 1.0、1.25、
1.5、2.0；更小视口不得绘制不可操作的菜单，保持长按不切布局并提示尺寸不足，短按仍可
切换单/四视图。这个下限是本轮适配约束，不是 Maya 的限制。

## 5. 输入契约

默认触发 Space，使用实际 invoke 键追踪释放。短按默认 0.4 秒，范围 0.1–1.0 秒；
等于阈值为保持。它不是菜单强制等待时间。按下立即具备交互资格，并在下一次可用重绘显示。

| 事件 | 结果 |
|---|---|
| 触发键按下 | 捕获原始面板/模式/场景，显示主热盒；不显示七向视图 |
| 短按无鼠标菜单操作后释放 | 清理后单/四视图切换一次 |
| 保持后释放 | 关闭，不切布局 |
| 中央 RMB 按下 | 展开七向视图，以该次鼠标按下处为划选原点 |
| 默认中央 LMB/MMB 按下 | 同一视图菜单；个人配置可分别覆盖，RMB 对齐是必测路径 |
| 菜单标题 LMB 按下 | 打开对应下拉菜单，取消短按资格；不触发中央视图菜单 |
| 鼠标移动 | 只更新布局命中、候选及子菜单；不执行命令、不改选择 |
| LMB 在菜单标题或子菜单父项上释放 | 保留已打开菜单；之后在叶项重新按下/释放可提交，支持点击式浏览 |
| 活跃鼠标键释放在有效叶项 | 命令提交一次；普通即时命令返回主热盒 |
| 鼠标释放在空白/禁用项/死区 | 不执行，返回主热盒；不恢复短按资格 |
| 开始菜单交互后先释放 Space | 取消未提交候选并关闭；后续鼠标释放不得穿透为一次模型操作 |
| Esc / 失焦 / 源上下文失效 | 清理并取消；已提交命令不隐式撤销 |

无论哪一个鼠标键开始操作，本次会话只认一个活跃手势键；其他键不能抢占或造成双提交。
自动重复不重开、不重计时。退出或失焦后必须可靠重置触发键保护，不留粘住菜单。
命中优先级：已展开子菜单 > 菜单标题/中央功能按钮 > 中央区域 > 周边区域。
周边未接入区域吞掉本次菜单点击并清除短按资格，不触发另一个视图或模型操作。

|---|---|---|---|

| NE | 无视图项 | 无 | 不人为补第八方向 |

### 弹窗、交互工具与关闭后的键释放

任何会启动另一个 modal operator、文件选择器或改变当前编辑器类型的命令，必须先结束
热盒 UI、验证上下文，再交给命令适配器；不能维持两个互相抢键的 modal 会话。
当前未释放的 Space 和手势鼠标 RELEASE 必须由窄范围结束态处理，不能传播成播放/选择，
也不能屏蔽新工具的后续正常输入。具体桥接接口在实施计划中依据 Blender 现有机制选择，
不得以重写全局事件分发作为默认方案。若无法可靠桥接，相关命令应禁用并阻止该项验收。

## 6. 模块边界与上游维护

| 单元 | 职责 | 禁止承担 |
|---|---|---|
| 原生热盒状态机 | 按键生命周期、活动区域、菜单路径、提交/取消 | Maya 功能长表、几何运算 |
| 原生布局/绘制 | 行布局、下拉与七向命中、UI 缩放 | 直接调用 UV 算法或在 motion 中跑 Python |
| 声明式目录 | 稳定 menu/item ID、父子顺序、command ID、选项入口 | 复制 Autodesk 实现或任意代码字符串 |
| 命令适配器 | 能力查询、上下文解析、调用和结果 | 私自更改公共键位含义 |
| 视图模块 | 现有槽位缓存、七方向和布局动作 | 菜单行配置 |
| 配置层 | 公共默认、团队、个人覆盖、验证 | 保存用户场景指针或打包个人修改 |

目录在预设激活或配置重载时解析/校验；热盒打开时取只读快照，鼠标移动不重复解析 Python 配置。
命令执行前重新校验存活上下文与可用性，不能仅依赖菜单打开时的 enabled 状态。
已有 `commands.py`/`adapter.py` 模式继续沿用，新增结构集中在 AxisMeld 模块和窄编辑器接口。
保留原有 profile schema 1 的读取；菜单配置采用独立版本化配置，不偷偷扩张旧键位项语义。
ID 重复、悬空子菜单、循环、无效鼠标键或未知命令都使当前覆盖层原子回退，不能半应用。
发行默认和用户个性修改分离；停用热盒后的 Blender 原生回落行为不变。

### Recent Commands

仅记录本热盒成功提交、适配器明确标记可重放的叶命令，最多 10 项，重复项移到最前。
不记录取消、失败、仅导航菜单、文件路径、对象引用或任意脚本；本轮会话内存储，不写磁盘。
重放按当前合法上下文执行并再次校验，不重用旧对象/区域指针。与 Maya 完整历史覆盖有差异，需标 adapted。

## 7. UV 预留契约

热盒只调用 `uv.*` 稳定语义命令，UV 工作区和算法提供实现。声明记录作用对象、对象/组件
选择要求、UV 层、调用来源、参数入口、是否交互、撤销边界和能力状态。

从 3D 视图发起的 UV 命令必须显式解析网格及 UV 层；需要 UV 编辑器时通过工作区适配接口
打开/定位，不能临时把任意用户面板改成 Image Editor 再假装还原。跨编辑器上下文须验证
当前选中对象和 UV 层；不凭“最后一个活跃 UV 窗口”猜测目标。

规划组：UV Editor、创建/投射、选择与 shell、Cut/Sew、Unfold/Optimize、对齐/拉直、
Layout/密度/UDIM、检查与可视化。完整名称清单见菜单对照表。
这些是接口规划，不表示 Blender 原生同类 operator 与 Maya 算法等价；不得标为 exact。
UV 算法、数据迁移、UI 和热盒分离；后续算法替换不改变热盒路径和公共 command ID。
