# 热盒避让可见区域设计

用户于 2026-09-14 要求暂停人工测试、按后续列表逐步修复问题与缺失能力。本片先完成已知窄视口遮挡修复；原 62 项人工测试保留待测，不等待人工验收才继续下一片。

## 现状与目标

当前热盒以完整 WINDOW region 布局。位于 WINDOW 内部的 Tool Header 可以覆盖原生列表导航行；松键后没有热盒 modal 残留，但停在该横条上的 W/E/R 进入工具栏上下文。既有测试把鼠标移回视口中心后再验证，未覆盖原地恢复。

目标是在用户原有工具栏/侧栏配置下，把可见按钮及其命中区域放到无遮挡区域，保持松键取消后原地 W/E/R 可用。先在现版本复现，修复不改变全局键盘焦点、鼠标位置或 release guard。

## 采用方案

- 保持事件、真实 press origin、pointer、死区与返回状态均为原 WINDOW 逻辑坐标。
- 捕获可见的对齐 overlap 兄弟 region，求保守无遮挡布局矩形；不能仅依赖只裁贴边遮挡的 ED_region_visible_rect。TOP 从其下缘裁上界，BOTTOM/LEFT/RIGHT 对称处理；不创建通用障碍物绕行系统。完全隐藏且动画结束的区域不参与，动画中保守使用输入路由仍采用的完整 winrct，四视图只计算与当前 WINDOW 相交的部分。
- 仅在纯布局入口把 center/popup origin 转为安全矩形的局部坐标；布局完成后将 rects、return_regions、marking_gaps 一起平移回原 WINDOW 坐标。字体、按钮尺寸、Views 横向净距不改变。
- 空间不足继续采用已有分页/原子拒绝规则，不缩小 Views 间距、不把部分不可点击的热盒绘出。
- 在 draw/event 生命周期检查遮挡区域是否改变。变化时取消并按既有 ownership 清理，不复用旧坐标，也不保存未经存活验证的兄弟 region 指针。

## 验收

1. 原窄窗禁用 Previous 行，按住 LMB 后分别 Space 先松/Esc 取消，补齐释放；不移动鼠标直接 W/E/R，真实工具身份正确，modal 清空，无意外设置或命令提交。
2. 实际列表不与可见 Tool Header/侧栏重叠；导航行、label、radio 可读，启用箭头和真正设置仍可点击。
3. 纯布局测试覆盖非零偏移、内部横条、左右侧栏、隐藏障碍、极窄安全区域、边缘起点、返回区和缺席方向同移；Views 与 QWER/组件/创建的净间距回归不变。
4. 标准视口、1x 窄窗、2x 四视图、工具栏/侧栏显隐与尺寸变化；后者保证旧会话安全取消。

M2d、QWER 高级能力和 M3 算法缺口继续独立分片；UV 与 Global 物体缩放不在本片实施。
