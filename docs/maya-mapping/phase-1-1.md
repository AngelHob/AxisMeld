# Phase 1.1：操纵器选轴与中键拖动

状态：开发验证中；未作为验收通过的发布版本。

## 如何使用

选择 **Edit → Preferences → Keymap → AxisMeld Maya 2026**。已有该预设时重新启动
本次构建，或点 **Reload AxisMeld Profiles**。无需安装插件，不修改个人配置文件。

1. 在 3D 视图选中可编辑网格，按 W / E / R 选择移动 / 旋转 / 缩放工具。
2. 在操纵器的 X / Y / Z 单轴上点一下并松开，不拖动；选中轴保持黄色。
3. 把指针移到视图空白区域，按住中键拖动。沿选中的轴执行当前变换。
4. 松开中键确认；拖动中按 Esc 或右键取消。可继续中键拖动，不必每次重新点轴。

直接左键拖动操纵器继续沿用 Blender 原生路径。没有选轴时，中键沿用原有自由变换。
Alt + 中键仍为平移视图。空闲时 Esc 清除保持的轴；切换工具、活动物体、Object/Edit
模式或预设会清除旧状态。状态仅属于当前视图，不写入 `.blend` 或个人偏好。

## 人工验收表

| 编号 | 测试操作 | 预期 |
|---|---|---|
| M1 | W → 点 X → 松开 → 空白处中键斜向拖动 | 仅 X 方向移动；选轴本身不移动物体 |
| M2 | E → 点 Z 环 → 空白处中键拖动 | 绕 Z 轴旋转；不是自由旋转 |
| M3 | R → 点 Y → 空白处中键拖动 | 仅 Y 方向缩放 |
| M4 | 同一工具下连续多次中键拖动 | 持续使用已选轴，每次松键单独确认 |
| M5 | 拖动中按 Esc；另一次按右键 | 恢复本次拖动开始前的数据 |
| M6 | 确认一次拖动后 Ctrl+Z | 一次撤销对应一次变换，选轴不占撤销步骤 |
| M7 | 在轴上按住左键直接拖动 | 原生直接拖动正常，不要求先单击 |
| M8 | 选轴后切换 W/E/R、Q、物体或 Object/Edit | 不误用旧工具/物体的轴状态 |
| M9 | 网格 Edit Mode 中选择部分组件，重复 M1–M6 | 仅所选组件执行约束变换 |
| M10 | 选轴后 Alt+中键拖动 | 平移视图，物体不变换 |
| M11 | 选轴后空闲时 Esc，再中键拖动 | 清除轴，回到原有自由变换行为 |
| M12 | 切回 Blender / Industry Compatible 预设 | 不保留 AxisMeld 选轴行为 |

## 已知边界

- 当前对齐的是点选轴与后续中键拖动的事件逻辑；坐标系、枢轴、变换数值和投影仍由
  Blender 计算，不宣称与 Maya 完全一致。
- 平面、中心、轨迹球、临时枢轴、吸附与工具按住菜单不在本次范围。
- Blender 按 Object / Edit 模式分别记录活动工具；进入另一模式后可能需要重新按 W/E/R。
- F8–F11 初次失效未能复现，暂不做猜测性修复。
- 用户报告的轻微卡顿仍需区分首次初始化、工具切换和拖动帧耗时。命令计时不是
  鼠标到画面的延迟测量，不能凭自动测试通过就认定手感或卡顿已修复。

## 开发验证

原生状态测试覆盖保持、替换、清除和上下文隔离；键位测试覆盖优先级与其他编辑器保护。
`axismeld_manipulator_ui_runner.py` 用独立临时配置和隐藏 GUI 测试进程回放真实 Blender
事件，不向用户正在使用的进程发送输入，也不保留测试场景或偏好。Blender 自动生成的
退出恢复快照仅允许写入测试独占的临时目录，并在测试退出后随该目录清理。
`axismeld_input_benchmark.py` 仅测命令分发耗时，并注明缓存与测量范围。

本机一次后台计时：原生命令中位数约 0.044 ms，AxisMeld 分发约 0.072 ms。
这是先原生、后适配器的顺序测量，存在共享缓存；没有测量 GPU 绘制、鼠标到画面延迟，
不能据此宣称轻微卡顿已解决。
