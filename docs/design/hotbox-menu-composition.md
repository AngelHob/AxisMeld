# 热盒与普通菜单的组合规范

用户于 2026-09-10 明确要求长期采用此规范，后续会有多处同类设计。

- **热盒**用于方向明确、适合肌肉记忆的快速操作，例如视图切换。
- **Blender 原生普通菜单**用于设置、选项列表及需要逐级浏览的目录，例如 Hotbox Style。
- 两者可以组合与级联；不要把全部子级都画成环形／椭圆按钮，也不要把普通选项画成分散的大卡片。
- 普通菜单继承 Blender 的背景、连续菜单项、字体、悬停高亮和禁用样式，复用原生组件。
- 父级热盒保持显示；子级活动时避免输入穿透。按键所有权、松键返回、Space 关闭与取消必须统一。
- 主热盒与二级热盒的尺寸独立；缩小二级按钮不等于缩小字体，也不压缩一级中央安全留白。
- 未实现功能仍保留灰显占位，不用可点击空操作冒充已接入功能。

新交互应先决定内容属于哪一类，再选择容器；不能仅按菜单层级决定一律使用热盒。
