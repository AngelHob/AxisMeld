# Phase 2A：视图热盒人工验收

状态：本地自动化回归与代码审查通过，等待人工验收；未批准集成或发布。Phase 1.1 仍为待最终审核状态。

## 范围与使用

选择 **AxisMeld Maya 2026** 键位预设。在 3D View 的 WINDOW 区域、Object Mode 或
网格 Edit Mode 中使用；不要求存在选择。Space 短按默认阈值为 0.4 秒，可在
**Edit → Preferences → Keymap** 的预设偏好中调整为 0.1–1.0 秒。

- 短按 Space：当前面板在单视图和四视图间切换。
- 按住 Space：立即显示四向视图入口；向上为透视、向右为侧视、向下为前视、向左为顶视。
- 从中心按住左键拖向有效方向，释放左键执行一次；释放 Space 关闭。
- 中心死区为 12 个逻辑像素；精确对角线不选择命令。

## 已知边界

- 仅实现四项视图入口，不是完整 Maya hotbox、菜单行或视角集合，也不包含 UV 功能。
- 隐藏的单视图槽位只在当前运行期缓存；保存并重启只保留当前可见视图，不保存隐藏槽位。
- 四视图 BOXCLIP 若暂时缺少 TOP/BOTTOM 或 FRONT/BACK 的完整贡献面，会保留最后有效
  裁剪体而不随该次导航更新；贡献面恢复后重新计算。这是当前的安全适配行为。
- 为保持原始指针与快速 marking 起点，视口边缘的标签允许被裁切，不保证总是完整可读。
- Phase 1.1 的 Global 缩放保持 Blender 原生行为，用户决定无需开发，暂无开发计划。
- 自动化合成事件不能证明视觉平滑度、物理键盘重复边界、实际鼠标手感或 XR 设备行为。
