# 极低窗口热盒说明验收

日期：2026-10-11。设计见[极低窗口说明避让与主干同步](../development/2026-10-11-short-window-and-upstream.md)。本文件记录第一阶段说明修复；此阶段尚未合入 Blender 5.4 主干。

## 范围与旧版复现

旧版只按全窗口宽度测量说明并沿 Y 轴寻找空带；所有候选失败后仍使用初始位置，导致说明背板覆盖菜单。已发布 interaction preview 在实际 **840×480、150%** 窗口中悬停 Space → Edit → Duplicate Special，最终观察器的菜单零交叠断言失败。旧版和首个新候选使用同一观察器 SHA `43416f40ad59084b1bd115abc3a6fecfe45280639e20c6a394cd78fc5615b435`。

说明先保留原有能放下的位置；必要时在窗口与实际菜单背景边缘之间寻找二维空白区域，并按候选宽度重新测量完整文字。原生列背景、分隔区、Options 和保留父级均参与避让，菜单布局、字号、命中与输入逻辑不变。用户已明确：无法容纳完整说明时暂不显示；恢复足够空间后应重新完整显示。
