# B12-11：四视图工具事件顺序修复

日期：2026-09-10。本次针对用户确认的“进入四视图后 W/E/R 像抓取工具、点轴不能保持激活”。不把重启恢复当作修复，也不保证所有长会话偶发现象均由同一原因导致。

## 根因与修复

`refresh_quad_clipping(layout_changed)` 为了立即获得四视图矩形，调用了只更新尺寸的初始化路径。该路径提前向三个新建 WINDOW 注册编辑器快捷键；稍后的完整初始化只追加默认 gizmo/tool handlers，已有 handlers 去重但不会重排。原来的第一个 WINDOW 已有正确顺序，因此表现不同。

修复仅将这一拓扑变化分支改为 `ED_area_init`：先装入默认工具/手柄事件，再装入编辑器快捷键，同时得到裁剪所需的新矩形。没有修改变换数学、用户快捷键、全局事件系统或保存偏好。
