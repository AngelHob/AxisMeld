## 这次改动

五行方向热盒的第二/四行与第三行横向净距直接对齐四视图 Views 的实际中心宽度。旧实现虽然共用间距常量，普通热盒却保留 24 宽中心，实际留白分别只有 8/40；本次统一实际内缘距离，并同步中心取消、空方向阻挡和外延命中。保留原五行方向、24 高按钮及持住 QWER 反复按 LMB 的操作。

四视图已写入根 AGENTS.md 和布局契约，作为后续方向热盒的标杆；新增测试比较全部 24 个径向菜单的实际几何，覆盖不同标签宽度及边角夹紧。设置、选项和深目录使用原生列表，支持分页以及真实 radio/checkbox 状态。

M3 共登记 **562 个语义命令**。Select / Modify / Edit / Create / Display / Mesh / Edit Mesh / Mesh Tools / Mesh Display / Curves / Surfaces / Deform 均接入；Blender 扩展保留原生名称并按功能归组。固定原生调用与参数来自源码白名单，配置不能提供任意 operator/RNA 路径。

Maya 静态目录去重后共 763 个动作身份：301 个已适配、197 个范围内缺失能力有唯一计划、262 个明确后置、3 个动态依赖。选项框和重复菜单声明不作为独立几何功能计数。562 是注册命令数，301 是 Maya 动作映射数，两者不是同一口径。完整来源、默认输入/释放、作用模式、参数、差异、计划依赖与验收标准见逐项对照 JSON/Markdown。

只扩展主 Space 菜单和明确支持的 Curve / Surface / Lattice Edit 命令；旧 QWER/组件 RMB 仍限定原建模上下文。F9 仍是 Vertex，参数入口为 **Space → Edit → Adjust Last Operation** 或原生工具/Modifier 属性。
